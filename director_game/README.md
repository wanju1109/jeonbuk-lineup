# 같은 축구, 다른 우리 — 축구 취향 테스트

기존 `/director_game/` 주소를 주제 선택형 테스트로 전환했습니다. `/director_game/admin.html`은 링크/iframe 복사 전용 공개 페이지입니다. 인증된 관리자 시스템은 아니며 비밀 정보가 없습니다.

## 구성

- 나는 어떤 단장일까: 영입, 계약, 성과의 시간, 근거, 자원 배분과 팀의 약속.
- 나는 어떤 팬일까: 직관, 동행, 기억, 루틴, 감정과 일상의 리듬.
- 나는 어떤 축구를 좋아할까: 전진, 공간 위험, 창의성, 패턴과 경기 흐름.
- 주제별 서로 다른 20문항, 총 60문항. 각 문항은 상충하는 3개 선택지이며 정답/점수가 없습니다.
- 상단 현재 번호/전체 문항, 답변 완료 막대. 선택지 순서는 시작 시 섞고 같은 테스트 안에서는 유지합니다.
- 이전 응답은 선택 표시와 함께 복원됩니다. 과거 답을 바꿔도 이후 답은 유지되며 다음 버튼으로 이동 가능합니다.
- 결과에서 마지막 질문 또는 임의의 질문으로 돌아가 수정할 수 있고 완료 시 전체 결과를 다시 계산합니다.
- 결과는 대표 이름, 네 관점의 방향, 실제 답변 인용, 반대 방향의 답, 감수할 대가, 다른 취향과 대화하는 방법, 작은 실험으로 구성합니다.
- 닉네임은 선택 사항. 결과 요약 복사에는 링크가 없으며 자동 복사 실패 시 수동 복사를 제공합니다.
- 답과 닉네임은 메모리에만 존재합니다. 서버/브라우저 저장소에 보관하지 않으며 새로고침하면 초기화됩니다.

## 해석 설계와 한계

이는 창작한 재미용 축구 취향 테스트입니다. 임상·심리측정 검증을 거친 검사가 아니며 실제 성격, 전문성, 팬심, 능력이나 경기 성과를 진단·예측하지 않습니다. 아래 검증은 소프트웨어 동작과 설계 일관성에 대한 검증입니다.

각 주제에 독립적인 4개 양방향 관점이 있고 각 관점을 주로 묻는 질문이 5개씩 있습니다. 각 답은 주 관점(-2/0/+2)과 별도의 보조 관점(-2~+2)에 기여합니다. 축별 선택지 기여도가 비대칭인 경우 한쪽으로 쏠리지 않도록 각 문항의 선택지 평균을 중립 기준으로 사용합니다.

관점별 원점수 S, 문항별 선택지 평균의 합 B, 가능한 최솟값 L/최댓값 H에 대해 S≥B일 때 `(S-B)/(H-B)`, 나머지는 `(S-B)/(B-L)`로 -1~1에 놓습니다. 절댓값 .18 미만은 혼합, .5 이상은 비교적 뚜렷한 방향으로 표현합니다. 이 구간은 콘텐츠 설계 기준이며 인구 통계적 백분위나 진단 절단점이 아닙니다. 화면에 확률·심리 정확도 퍼센트를 표시하지 않습니다.

대표 이름은 절댓값이 가장 큰 관점에서 정하며 동률은 관점 순서로 결정합니다. 네 관점을 모두 보여 대표 이름 하나에 의미를 과도하게 싣지 않습니다. 근거 인용은 해당 답변의 평균 대비 기여 방향으로 선택하되 주 관점 문항을 우선합니다. 반대 답변도 있으면 함께 보여줍니다. 질문 내용과 배점은 공개 소스이며 결과를 숨기는 보안 장치는 아닙니다.

## 파일과 검증

- `topics.js`: 3개 주제, 60문항, 관점 설명 및 대가.
- `engine.js`: 검증, 점수 정규화, 근거 선택, 해석 및 복사 텍스트.
- `app.js`: 주제/질문/결과 흐름, 수정 및 클립보드.
- 기존 `players.js`는 과거 영입 게임 자료로만 남아 있으며 새 화면에서는 로드하지 않습니다.

2026-09-17 검증:

- `node director_game/scripts/test_engine.cjs`: 주제별 1,500개, 총 4,500개 응답 조합. 실제 답변과 인용 일치, 동일 답의 동일 결과, 다양한 유형 도달, 각 관점 양극 도달, 문항 분배 및 잘못된 응답 거부 통과.
- `node director_game/scripts/test_browser.cjs`: 5가지 화면(1366×900 / 975×800 / 390×844 / 375×667 / 320×568), 세 주제의 전체 60문항, 이전 응답 표시/변경, 이후 응답 보존, 결과 재계산, 상세 해석, 닉네임/복사/수동 대체, 실제 iframe 검증 통과.
- 모바일 주제 선택, 질문, 상세 해석 화면 시각 검토 완료.
- 브라우저 검증은 저장소 루트의 HTTP 서버(127.0.0.1:8765)와 Playwright/Edge를 사용합니다. `DIRECTOR_URL`로 공개 주소 검증 가능.
