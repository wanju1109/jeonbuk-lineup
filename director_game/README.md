# 전북 단장 · 딱 한 명만

- 참가: `/director_game/` — 시작 버튼 없이 첫 영입 카드 3장을 표시합니다.
- 공유 관리: `/director_game/admin.html` — 링크와 iframe 복사. 인증이 있는 관리 기능은 아니며 비밀키를 사용하지 않습니다.
- 5번의 선택: 전성기 영입 → 영입 조건 → 조건에 맞는 보강/유스/훈련 → 운영 방향 → 가상 결승 80분 판단.
- 국내 선수 조건은 김보경/최철순/권순태 중 추가 영입, 유스 조건은 가상 육성 프로젝트, 영입 종료 조건은 기존 팀 훈련으로 분기합니다.
- 2단계 운영 조건을 제외한 4번의 선택에서 공격/중원/수비 선택 횟수를 요약합니다. 최다 항목으로 성향을 표시하고 동률은 균형형입니다. 실제 능력치, 경기 시뮬레이션, 우승 확률, 순위가 아닙니다.
- 이전 선택으로 돌아가면 이후 선택은 새로 고릅니다. 결과에는 영입 명단과 조건·전술·마지막 결정을 표시합니다.
- 닉네임은 선택 사항이며 댓글용 보고서에만 포함합니다. 게임 링크를 복사 내용에 넣지 않습니다. 자동 복사 실패 시 수동 복사를 제공합니다. 서버/브라우저 저장소에 기록을 저장하지 않습니다.

## 자료 및 화면

선수 이름·공식 선수별 기록 링크·사진 주소는 저장소의 `player_quiz/data/39847ef56fbbf639.json`에서 확인한 6명을 사용합니다. 사진은 해당 외부 주소에서 직접 표시하며 실패하면 자체 SVG 유니폼으로 대체합니다. 전성기 영입과 계약 조건·결승 상황은 창작 시나리오입니다. 카드 문구는 가상의 영입 의도이며 검증된 능력치 순위가 아닙니다.

모바일에서는 세 카드를 세로로, 넓은 화면에서는 가로로 표시합니다. 사진이나 외부 폰트가 없어도 플레이할 수 있습니다. 관리자 페이지 없이도 기본 주소를 공유하면 됩니다.
