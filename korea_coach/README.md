# korea_coach — 한국 감독

2026시즌 **K리그1·K리그2 한국인 사령탑**과, 리그 밖에 있는 **P급 한국 감독**의 연대기·축구·능력치를 칼럼으로 읽고 비교하는 페이지입니다.
외국인 사령탑은 넣지 않았습니다.

대한축구협회는 P급 전체 명단을 공개하지 않습니다. 이 페이지는 현역 K리그 한국인 감독과, 대표팀·해외·원로 등 확인된 주요 P급을 수록합니다.

## 데이터

```powershell
python korea_coach/scripts/build_coaches.py
```

초상은 위키미디어 공용에서 받은 파일을 `korea_coach/img/`에 둡니다.
뉴스·구글 검색 사진은 저작권 때문에 쓰지 않습니다. 공용 초상이 없으면 이니셜로 대체합니다.

기록의 근거는 한국어 위키백과 감독 항목, 2026 개막 미디어데이 보도, `team_report` 프로필입니다.
현재 점수는 **현 소속팀 재임 리그 성과**입니다. 공식 경기 결과로 계산하며 이름값과 수동 능력치를 합산하지 않습니다.

- 재임 성과 50%: 같은 기간·같은 리그의 보정 PPG 백분위
- 기준 대비 변화 30%: 전년 또는 부임 전 같은 리그 대비 성과 변화
- 최근 8경기 20%: 보정 PPG 백분위

8경기 미만·대표팀/해외/무직 등 동일 자료가 없으면 평가 보류입니다.
기존 능력치(20점)는 전술 메모 안에 분리했고 총점에는 사용하지 않습니다.
상세 산식은 [SCORING.md](SCORING.md), 전원 계산 내역은 [scoring_audit.json](data/scoring_audit.json)을 참조하세요.
기존 proto 일일 갱신에서 공식 경기 자료와 함께 감독 성과도 다시 계산합니다.
