# korea_coach — 한국 감독

2026시즌 **K리그1·K리그2 한국인 사령탑**과, 리그 밖에 있는 **P급 한국 감독**의 연대기·축구·능력치를 칼럼으로 읽고 비교하는 페이지입니다.
외국인 사령탑은 넣지 않았습니다.

대한축구협회는 P급 전체 명단을 공개하지 않습니다. 이 페이지는 현역 K리그 한국인 감독과, 대표팀·해외·원로 등 확인된 주요 P급을 수록합니다.

## URL

```text
https://wanju1109.github.io/jeonbuk-lineup/korea_coach/
```

- 에버그린 공유: 메인 화면 (`/korea_coach/`). 받은 사람이 K리그1·K리그2·기타에서 감독을 고릅니다.
- 특정 감독 북마크: `?q=<opaque>`
- 두 사람 비교 북마크: `?q=<A>&v=<B>`
- 작성자 화면: `?x=jb7k`

공유 링크에는 작성자 키를 넣지 않습니다.

## 탭

- K리그1 / K리그2 / 기타 / 비교
- 명단은 모두 이름순입니다.
- 기타: 국가대표, 해외 벤치, 무직·단장·원로 등 K리그 사령탑이 아닌 한국 P급. 자음(ㄱㄴㄷ)으로 묶습니다.
- 대한축구협회는 P급 전체를 공개하지 않아, 나무위키 한국 감독 목록을 그대로 옮기지는 않습니다. 확인된 주요 이름만 수록합니다.

## 데이터

```powershell
python korea_coach/scripts/build_coaches.py
```

초상은 위키미디어 공용에서 받은 파일을 `korea_coach/img/`에 둡니다.
뉴스·구글 검색 사진은 저작권 때문에 쓰지 않습니다. 공용 초상이 없으면 이니셜로 대체합니다.

기록의 근거는 한국어 위키백과 감독 항목, 2026 개막 미디어데이 보도, `team_report` 프로필입니다.
추천도(100점)와 능력치(20점)는 편집부 해석이며 게임 데이터가 아닙니다.
공격·수비 점수와 성향(공격형/수비형/밸런스)도 같은 해석입니다.
