# 나는 누구일까요? — K리그 선수 맞히기

## 참가자와 관리자

- 참가 화면: `player_quiz/index.html`. 참가자가 선수 범위, 난이도, 문제 수를 직접 선택합니다.
- 관리자: `player_quiz/admin.html`. 조건 설정 없이 공통 게임 링크와 iframe 코드만 복사합니다.
- 관리자 링크/iframe은 항상 참가자의 선택 화면으로 연결됩니다.
- 세 가지를 모두 선택하면 시작 버튼이 표시됩니다. 선택 카드는 설명, 출제 가능 인원, 힌트 수, 체크 표시를 제공합니다.
- 범위는 현재 전북 / 역대 전북 / 현재 K리그1 / 현재 K리그1+2입니다.
- 하/중/상 기본 힌트 5/3/1개, 5/10/20문제를 선택합니다.

## 플레이

문제당 10초이며 긴 바가 줄어듭니다. 정답·오답·시간 초과 결과를 2초간 보여준 뒤 자동 진행합니다. 정답 100점, 추가 힌트당 20점 차감(최저 20점), 오답·건너뛰기·시간 초과 0점입니다. 힌트는 시간을 늘리지 않습니다. 중도 포기를 확인하면 진행 점수와 모든 타이머를 초기화합니다.

최종 결과 복사는 점수·정답 수·스포일러 없는 타일·동일 도전 링크를 포함합니다. 이 결과 링크는 처음에 같은 조건을 표시하지만 모든 설정을 참가자가 바꿀 수 있습니다. 조건을 바꾸지 않고 시작하면 같은 문제와 순서가 유지되며, 바꾸면 새로운 도전입니다. 관리자 공유 링크는 조건이 없는 기본 주소입니다.

## 출제 기록

생년월일·키·국적 대신 공식 시즌/통산 출장·득점·도움, 골키퍼 실점·클린시트, 전북에서 기록이 있는 시즌, 포지션·등번호 등을 사용합니다. 컵·플레이오프·ACL은 K1/K2 집계에 포함하지 않습니다. 이적 선수의 같은 시즌 기록은 합산하고 미확인 값은 0으로 만들지 않습니다. 최신 시즌 기록이 없으면 마지막 기록 시즌을 명시합니다. 전체 순위와 수상 자료가 없는 한 최다/1위/베스트11 횟수는 생성하지 않습니다.

역대 전북은 공식 선수 검색, 보유 선수 경력, 공식 상세 기록으로 확인한 보완 명단을 합칩니다. 창단 이후 모든 등록 선수의 완전한 수록을 보증하지 않으며, 축구 힌트가 5개 미만인 선수는 제외합니다. 최신 데이터는 1,016명(전북 현재·역대 217명)입니다.

`build_data.py`는 SHA-256 앞 16자리로 데이터를 저장합니다. **공개한 버전 파일은 삭제/덮어쓰지 마세요.** 이전 결과 링크를 재현하는 데 필요합니다. `manifest.json`은 새 게임에 사용할 버전입니다. 출제 엔진은 데이터의 hintPolicy에 따라 과거 버전의 순서를 유지합니다.

## 운영 및 검증

```text
python player_quiz/scripts/collect_history.py
python player_quiz/scripts/build_data.py
python -m http.server 8765 --bind 127.0.0.1
node player_quiz/scripts/test_engine.cjs
python player_quiz/scripts/test_records.py
node player_quiz/scripts/test_browser.cjs
node player_quiz/scripts/test_timer.cjs
```

브라우저 검증은 Playwright와 Edge를 사용합니다. 전체 검증 기록은 VALIDATION.md를 참고하세요.

참가 화면에 관리자 도구는 없지만 관리자 URL 자체에 인증은 없습니다. 정답·점수는 정적 팬 게임의 클라이언트 데이터이며 공인 순위가 아닙니다. 개인정보·비밀키를 저장하지 않고 응답·점수를 서버로 보내지 않습니다. 새로고침하면 처음부터 시작합니다.
