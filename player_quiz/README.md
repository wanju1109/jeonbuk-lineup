# 나는 누구일까요? — K리그 선수 맞히기

- 참가 화면: `player_quiz/index.html`
- 출제 도구: `player_quiz/admin.html`
- 범위: 현재 전북 / 역대 전북 / 현재 K리그1 / 현재 K리그1+2
- 4지선다, 5·10·20문제. 난이도 하/중/상은 기본 힌트 5/3/1개.
- 정답 100점, 추가 힌트당 20점 차감(최저 20점), 오답·건너뛰기 0점.
- 같은 링크는 데이터 버전·시드·난이도·범위·문제 수가 고정됩니다.
- 결과 복사는 점수·정답 수·스포일러 없는 정답 타일·동일 도전 링크를 포함합니다.

## 데이터와 범위

`collect_history.py`는 K리그 공식 선수 검색(type=all, teamId=K05, GK/DF/MF/FW)의 페이지를 수집하고 공식 playerDetail 프로필을 저장합니다. 현재 등록 명단은 기존 `player_report/data/index.json`을 사용합니다. 기존 선수 프로필에서 전북 시즌 기록이 확인되는 다른 팀 현역도 역대 범위에 포함합니다. 공식 검색이 경력을 완전히 포괄하지 않을 수 있으므로 창단 이후 모든 등록 선수를 빠짐없이 확보했다고 주장하지 않습니다. 5개 이상의 구조화된 힌트가 있는 선수만 출제합니다. 주관적 스카우트 문구는 사용하지 않습니다. 기록의 팀 목록은 K리그 기록이며 해외 경력을 포함한 전체 이력서가 아닙니다.

`build_data.py`는 데이터 SHA-256 앞 16자리로 파일을 저장합니다. **한 번 공개한 버전 JSON을 삭제하거나 덮어쓰지 마세요.** 기존 링크의 문제와 보기 순서가 보존됩니다. 선수 업데이트를 반영하려면 빌더를 다시 실행하면 됩니다. 이전 도전은 출제 당시 명단·등번호 기준입니다.

## 관리자 화면에 관하여

참가 화면은 출제 UI나 출제 도구 링크를 포함하지 않습니다. 하지만 GitHub Pages에서 별도 URL을 만드는 것은 인증이 아닙니다. `admin.html` 주소를 아는 사람은 출제 도구를 사용할 수 있으며, 공개 데이터에 정답도 있습니다. 개인정보·비밀키는 없고 공유 결과는 공인 점수가 아닙니다. 접근 제어가 필요한 비공개 웹 관리자/순위표에는 별도 인증 및 서버가 필요합니다.

## 실행과 검증

```text
python player_quiz/scripts/collect_history.py
python player_quiz/scripts/build_data.py
python -m http.server 8765 --bind 127.0.0.1
node player_quiz/scripts/test_engine.cjs
node player_quiz/scripts/test_browser.cjs
```

브라우저 테스트는 `playwright`와 Edge를 사용합니다. 생성되는 스크린샷은 Git에 포함하지 않습니다. 참가자는 로그인 없이 플레이하며, 응답·점수를 서버로 보내지 않습니다. 페이지를 새로고침하면 도전이 처음부터 시작됩니다.

### 참가자 설정 및 기록 중심 힌트

게임 시작 화면에서도 선수 범위·난이도·문제 수를 직접 선택할 수 있습니다. 공유 링크에서는 고정된 조건이 먼저 나오고 '내 설정으로 새 게임 만들기'로 변경합니다. 중도 포기 시 확인 후 점수를 초기화하며, 결과에서도 설정 화면으로 돌아갈 수 있습니다.

새 문제는 생년월일·키·국적을 제외합니다. 포지션·등번호·등록 구단, 전북 기록 시즌, 시즌/통산 출장·골·도움 등을 사용합니다. K1/K2를 구분하고 컵·플레이오프는 제외합니다. 이적 선수의 같은 시즌 기록은 합산하고, 미확인 값은 추정하지 않습니다. 골키퍼는 실점·클린시트를 사용합니다. 최신 시즌 기록이 없는 선수는 마지막 기록 시즌을 명시합니다. 축구 기록이 부족하면 출제하지 않습니다.

추가 검증: `python player_quiz/scripts/test_records.py`.
