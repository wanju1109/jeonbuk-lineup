# 승부예측 검증 2차 — 2026-09-15

공식 경기 1,812건으로 모델을 다시 비교했습니다. **새 포아송은 신규 경기용 구모델보다 개선됐지만,
기존 저장 픽보다 적중률이 높지 않아 비교 모드로만 제공합니다.** 종료된 경기의 기존 픽은 수정하지 않습니다.

## 데이터 확인

[K리그 공식 일정](https://www.kleague.com/schedule.do)의 공개 JSON API로 2023~2026 K1/K2 종료 경기를 수집했습니다.
월별 요청 시각과 응답 SHA-256, 팀 공식 ID, 경기 ID, 날짜와 점수를 `data/official_history.json`에 저장합니다.
K2 시즌 말 플레이오프도 공식 일정에 포함된 범위입니다. 2026년 종료 381경기는 기존 점수와 모두 일치했습니다.
별도 `c_report` 상세 자료와는 11건의 점수 차이가 있으므로 상세 자료를 학습 원천으로 쓰지 않았습니다.

## 선정 및 평가

2023~2024년 928경기로 회귀 후보를 학습하고, 2025년 503경기에서 로그손실이 가장 작은 후보를 선택했습니다.
후보는 날짜 가중 포아송, Elo, 정규화 강도 2가지의 다항 회귀, 세 모델 평균의 총 5개입니다.
2026년 결과로 모델 종류나 매개변수를 다시 고르지 않았습니다.

선정된 모델은 포아송입니다. 홈·원정 분할 대신 양쪽 경기를 합쳐 팀의 공격·수비를 추정하고,
180일 반감기로 오래된 기록의 영향력을 줄입니다. 팀별 5경기, 리그별 12경기의 사전 평균으로 적은 표본을 보완합니다.
승격·강등 팀은 리그별 상태가 분리되어 해당 리그 자료가 없으면 사전 평균에서 시작합니다.
2026년 경기마다 같은 날짜와 이후 결과를 제외하고 확률을 먼저 계산한 뒤 상태를 갱신했습니다.

| 2026년 381경기 | 적중률 | 로그손실 | Brier |
|---|---:|---:|---:|
| 기존 신규 경기 포아송 재계산 | 142/381 = 37.27% | 1.124978 | 0.683689 |
| 새 날짜 가중 포아송 재계산 | 160/381 = 41.99% | 1.078555 | 0.652376 |
| 기존 저장 픽 | 166/381 = 43.57% | 비교하지 않음 | 비교하지 않음 |

새 모델의 적중률 95% Wilson 구간은 37.14~47.01%입니다. 기존 저장 픽에는 규칙·수동 판단이 섞여 있고
모든 사전 생성 시각을 증명할 수 없으므로 동일한 생성 과정의 모델 비교는 아닙니다. 그렇다고 이보다 낫다는 주장도 하지 않습니다.
이전 작업에서 2026년 결과를 이미 봤으므로 이번 2026년 비교를 완전히 독립적인 최종 시험이라고 부르지 않습니다.
이전에 보지 않았던 09-08 이후 18경기는 두 모델 모두 7/18(38.89%)로 차이가 없습니다.

## 확률과 선별

| 새 모델 최대 확률 | 경기 수 | 적중 | 전체 대비 비중 |
|---|---:|---:|---:|
| 45% 이상 | 190 | 45.79% | 49.87% |
| 50% 이상 | 110 | 50.00% | 28.87% |
| 55% 이상 | 55 | 56.36% | 14.44% |
| 60% 이상 | 31 | 67.74% | 8.14% |

이는 정해 둔 구간별 사후 참고 통계입니다. 60% 구간의 95% 적중률 구간은 50.14~81.43%로 넓습니다.
이 결과를 보고 60%를 자동 추천 기준으로 채택하지 않았고, 어려운 경기를 숨기거나 전체 적중률의 분모에서 빼지 않습니다.
0.5~0.6 구간은 평균 모델 확률 53.61% 대비 실제 43.04%여서 과신이 남아 있습니다.

## 이후 검증

`data/model_predictions.json`에 모델 버전·저장 시각·사용한 결과의 마지막 날짜·확률·이전 갱신 기록을 저장합니다.
다음 14일 경기를 갱신하며 기존 예측은 킥오프 24시간 이내에 고정합니다. 경기 시작 뒤에는 생성하거나 덮어쓰지 않습니다.
첫 생성이 24시간 이내인 경우에도 실제 생성 시각을 남깁니다. 시간이 없는 경기는 당일 00:00 KST를 보수적으로 사용합니다.
페이지의 새 모델 실전 집계는 종료 경기 중 현재 일정의 킥오프보다 앞서 저장된 예측에만 적용합니다.
원래 픽, U/O, 과거 결과와 별도로 관리합니다. 현재는 첫 저장 단계라 실제 종료 평가 표본이 없습니다.

## 재현

```text
python proto/scripts/collect_prediction_history.py
python proto/scripts/validate_model_v2.py
python proto/scripts/publish_model_predictions.py
python -m unittest discover -s proto/scripts -p "test_*.py"
node proto/scripts/test_prediction_display.cjs
```

첫 명령은 인터넷이 필요합니다. 나머지는 Python/Node 표준 라이브러리만 사용합니다.
일일 자동화는 공식 자료 갱신과 사전 예측 저장만 실행합니다. 모델 선정과 과거 보고서는 자동 재최적화하지 않습니다.
