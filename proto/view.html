예측 확률과 검증 결과 읽는 법

파란 체크는 저장된 픽입니다. 모델 확률 1위와 다른 기존 픽은 근거에 따로 안내합니다. 모델 40%는 비슷한 조건에서 해당 결과가 약 40%라는 추정이며, 확정이나 적중률 보장이 아닙니다. 배당은 확률과 단위가 다릅니다. 실시간 배당으로 픽을 바꾸지 않습니다.

새 검증 결과를 불러오는 중…

새 모델은 비교 검증 중입니다. 기존 픽을 유지하며, 다음 14일 경기의 예측을 매일 갱신하고 킥오프 24시간 이내에는 저장한 예측을 고정합니다. 경기 후 새로 만든 예측은 적중 집계에 넣지 않습니다.

시즌별·경기별 검증 JSON · 검증 방법과 한계

파란 테두리 + 체크 = 내 픽 파란 채움 = 픽이 실제와 같음(적중) 노란 채움 = 실제 결과(픽과 다를 때) 모델 % = 결과별 추정 확률 · 배당 = 배당률

불러오는 중…

저장된 픽과 모델 확률을 함께 표시합니다. 해외배당은 참고 정보이며 픽을 변경하지 않습니다. 모델 확률은 실제 적중률 보장이 아니며, 지난 경기의 픽은 보존합니다. 예정 경기는 분석하기를 눌러야 픽이 열립니다.
